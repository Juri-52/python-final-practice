# 第12回 Python総合演習

これまで学習したPythonを使い、**テーマの異なる3つの課題**に取り組みます。各課題は独立しており、前の課題のコードをコピーする必要はありません。

| 順番 | 課題 | 主なテーマ |
| --- | --- | --- |
| 1 | [成績レポート](01_score_report/README.md) | JSON、リスト、dataclass、例外処理 |
| 2 | [ロボットと充電ステーション](02_robot_station/README.md) | クラス、継承、オブジェクト間の連携 |
| 3 | [駐車場のシナリオテスト](03_parking_tests/README.md) | pytest、バグ修正、リファクタリング |

## 進め方

1. 各フォルダーのREADMEを読み、指定された部分を完成させます。
2. 第1・第2課題はひな形です。passを残したままでは、完成後の動作になりません。
3. 第3課題は、実行できますが状態管理に誤りがあるコードです。先にテストを書き、修正前と修正後を確認します。
4. これまでの授業資料を参照して構いません。新しいライブラリやGUIは必要ありません。

型ヒントはひな形に用意しています。追加するフィールドにも指定された型を書いてください。処理の結果を返すことと、画面に表示することを区別します。

## 準備と実行

PyCharmで授業用のPython環境を選びます。Python 3.10以降を使います。このREADMEのあるフォルダーで、pytestを準備してください。

```bash
python3 -m pip install -r requirements.txt
```

各課題の実行コマンドは、その課題のフォルダー内で実行します。PyCharmの実行設定を使う場合も、作業ディレクトリを該当する課題フォルダーにしてください。

## 提出

完成した3つのフォルダーを、授業で指定されたGitHubリポジトリへ提出します。READMEとscores.jsonも残します。仮想環境、キャッシュ、IDEの設定は提出しません。追加レポートは不要です。

- [ ] 第1課題で、合格者と人数が入力した基準に応じて変わる。
- [ ] 第1課題で、不正な入力を処理できる。
- [ ] 第2課題で、成功時だけロボットとステーションの状態が変わる。
- [ ] 第2課題で、継承したメソッドから子クラスの消費量が使われる。
- [ ] 第3課題の6つのテストに実際のassertがあり、すべて成功する。
- [ ] 第3課題で、失敗時の状態と操作の順序を確認し、処理を整理した。

評価では、実行結果だけでなく、データの扱い、失敗時の状態、継承の使い方、テストの内容、コードの読みやすさを確認します。
